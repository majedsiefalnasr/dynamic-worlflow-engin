## تحديث الحالة

عند بدء أي مرحلة يضاف:

- رابط branch أو PR للـBackend.
- رابط branch أو PR للـFrontend.
- رابط Swagger للمرحلة.
- أوامر الاختبار ونتيجتها.
- أي قرار جديد أو breaking change.
